# ICS-311-Slop
Website with 311 Notes and Help


An interactive study site for ICS 311 Topics 16–17: Disjoint Sets (Union-Find), Minimum Spanning Trees, Kruskal, Prim, and Fibonacci heap degree bounds.

- Topic notes, embedded course screencasts, and diagrams
- Step-through Kruskal and Prim visualizers
- Randomized multiple-choice and generated questions
- Pseudocode challenges graded on correctness, modularity, and efficiency
- "Dummy mode" switch with grade-school-level explanations

`index.html` is a self-contained build. Edit files in `src/` and run `python3 build.py`, then copy `dist/index.html` to `index.html`.
